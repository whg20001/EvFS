## 本地启动

需要 Node.js **22.19+**（本次验证为 22.23.2），建议 npm 12。

```sh
npm ci
npm run setup
npm run dev
```

打开 **http://127.0.0.1:3010**，点击「首次使用，创建账号」。用户名为 3–32 位字母、数字或 `._-`，密码至少 12 位。

- `setup` 以 `0600` 权限创建根目录 `.env`，不会覆盖已有配置。默认 `APP_STORAGE_MODE=local-first`；`ALLOW_REGISTRATION=false` 可关闭新账号注册。账号密码以独立随机盐和 scrypt 哈希保存，不写入学习备份。当前未提供邮箱验证或自助找回密码。
- Web 开发服务监听 `0.0.0.0:3010`，便于 Windows 宿主机访问 WSL；API 仍仅监听 `127.0.0.1:4000`。浏览器通过 Next.js 同源转发访问 API。开发服务不要暴露到公网。
- 新建账号库无需 Docker 或外部 PostgreSQL。默认模式不打开或改写旧 `data/mock` / `data/live` 学习库；旧数据迁移见下方「本地优先存储与迁移」。旧服务器模式的物理升级仍需停服备份。
- 默认学习数据保存在当前浏览器的 IndexedDB，按稳定账号 ID 和 mock/live 模式分库；换设备或清理网站数据不会自动恢复。云端账号及调用计量保存在 `data/cloud-accounts`（可用 `ACCOUNT_DATA_DIR` 修改）。API 重启后需要重新登录，本地学习数据继续保留。
- `.env`、数据库、测试结果均不应提交版本控制。
- 更换 Web 地址时同步设置根 `.env` 的 `APP_ORIGIN`；需要同时使用其他地址时，用 `APP_ALLOWED_ORIGINS` 显式列出额外完整来源（逗号分隔，包括协议与端口，不带路径）。不会根据请求 Host 自动放行，CSRF 校验仍保留。
- **Web dev/start 必须通过 npm scripts → `apps/web/server.mjs` 启动，不支持绕过该受控入口直接运行 `next dev/start`。**
- 更换 API 端口时，启动 Web 前还需显式设置 `API_INTERNAL_URL`（例如 `http://127.0.0.1:4100`）；它仅接受 literal loopback origin（`127.*` 或 `::1`），不接受 `localhost` hostname 或远程 API。

### Windows / WSL 无法访问时

先在 Windows 浏览器尝试 `http://localhost:3010`。若 localhost 转发未生效，在 WSL 执行 `hostname -I`，使用其中的 WSL IPv4 地址访问 `http://<WSL_IP>:3010`，并将这个完整来源加入根 `.env` 的 `APP_ALLOWED_ORIGINS` 后重启服务。WSL 重启可能改变 IP，需要同步更新。只开放 Web 端口，无须开放 API 的 4000 端口。

Next.js 的开发资源允许本机具体 IPv4 地址；应用登录/写入仍只允许配置的来源。HTTP 局域网访问不具备 HTTPS 的传输保护，请仅在可信本机/网络测试；生产 HTTPS 需独立受控部署，不能因此扩大代理信任。本轮未人工验收 Windows→WSL 真实网络访问。

## 已实现能力（离线回归通过）

- 三段复述、版本化自动保存、显式提交及不可变提交快照；本地待保存内容保留与冲突提示。未提交且有文字或附件的复述保留在「草稿箱」，支持跨天继续编辑、提交；主题、三段正文和参考资料一起保留，提交仍归属原学习日期，不占用第二天的复述。
- UTF-8 TXT、MD、Markdown 上传及粘贴笔记；文本型 PDF 本地解析、页码/全文行号定位及原文件下载；PNG、JPEG、WebP 经 BBC_OCR 识别、校对后导入；大小/数量/编码校验、原始字节与哈希持久化。PDF 的页数、文本上限和 OCR 边界见 [ADR 0006](./docs/decisions/0006-文本PDF与复习统计.md)，图片识别见下文。
- 原始笔记支持 Markdown/GFM、只读任务列表、代码着色和本地 KaTeX 公式，保留“原文（行号）”核对证据；来源右侧可最大化阅读，支持键盘、390px 移动端和深色；Markdown 文档最大化后提供可跳转大纲、原文行定位与滚动高亮，手机可折叠，无标题或 TXT/快照来源不显示大纲。Markdown/无扩展名文档默认排版，TXT 默认原文；新粘贴名称默认补 `.md`，历史快照仅原文。HTML 转义显示、图片全部占位，仅 http/https/mailto 链接可主动打开，不执行脚本或自动加载外部资源。见 [ADR 0005](./docs/decisions/0005-笔记Markdown渲染.md)。
- 用户确认/排除/修改知识点，跨天复用稳定知识身份；补充资料产生新的范围版本，旧问答保留。
- 范围确认修改在当前标签页缓存；离页提示、登录过期恢复及新范围冲突保护。交卷后可查看分项得分/依据、标记争议、人工核对或明确请求模型复评，保留历次评价与正式答案。
- 知识点可编辑名称、描述和标签，支持归档/恢复；归档退出搜索、联想及复习队列，历史来源、证据和排期记录保留。
- 本地资料库 BM25 搜索（中文/英文、原文行号、分页、可选个人理解与术语扩展）、历史文档显式引用、可选的“旧知识联想”（设置中开启，默认关闭）：自动选出最多 3 个相关旧知识点结合出题，不作来源、不合并、不扩大考核范围。复习出题可检索该知识点原始来源。
- 追问、主动结束、无测验结束；单选、简答与可选代码题、答案草稿、不可覆盖的正式答案、跳过与显式交卷。
- 答题前只返回当前题与已答题，不返回参考答案、评分细则或未来题目。简答和代码题 mock 只产生“待核对”，不编造分数。
- 知识库与个人理解笔记、学习历史、复习队列、独立回忆、一次有效复习一次排期事件。内容快照/证据版本、非空回忆用于出题及结束原因修复已通过离线回归。
- 持久化任务、单执行器、版本与 attempt fencing、超时/取消/显式重试、幂等收据；中断中的调用不自动重放。
- 密码访问、签名 HttpOnly/SameSite Cookie、CSRF/Origin 校验、登录限流、可选预算预留及任务次数上限。
- 数据迁移、学习数据 JSON 备份、确认后恢复/逻辑清空；桌面与手机页面。
- 30 条固定原创评估样例及报告工具，支持离线回归、API key 或应用内 OAuth；OAuth 复用应用队列与用量记账，无须停服或复制凭据。命令和实际结果见[评估说明](./docs/evaluations/README.md)。
- 顶栏「全部模块 → AI 配置」：自行选择 Provider、认证方式与目录模型，持久化偏好；授权区默认仅显示已连接项，添加/重新授权按需展开；手动连接测试、服务端加密凭据及 Pi 自动刷新；按年度/时区查看本应用 token 热力图。

演示期间，评价、证据和排期带模拟标记。真实模式的排期默认关闭，需要单独确认后启用。

## 本地优先存储与迁移

默认采用 **云端账号 + 浏览器学习数据库 + 按需 AI 网关**。设置 `APP_STORAGE_MODE=server` 可继续使用旧单用户服务器学习库，该模式额外需要 `OWNER_PASSWORD`。部署新版不会自动迁移或清空旧学习库，也不会自动复制旧共享 OAuth 凭据到新账号。

| 内容 | 默认保存或执行位置 |
| --- | --- |
| 笔记、资料原件、知识库、测验、复习、Skill、模型选择、任务结果与用量热力图 | 浏览器 IndexedDB，数据库名 `sanxing-learning-v1:<account-id>:<mode>` |
| 账号与管理 | `ACCOUNT_DATA_DIR`（默认 `data/cloud-accounts`），PGlite；用户名、随机盐、密码哈希、稳定账号 ID、角色、状态及额度 |
| 网关防重放及限额记录 | 同一账号库；仅请求 ID、HMAC、时间、状态、模型及数字用量，不保存任务正文和模型回复 |
| 活动与管理操作 | 同一账号库；登录/退出、模块访问、心跳时间及管理操作。活动保留 90 天，管理操作保留一年 |
| 平台 AI | 同一账号库；平台模型、额度和 AES-256-GCM 加密的 API key，依赖原 `SESSION_SECRET`；管理接口不会回显密钥 |
| 每个账号的 OAuth 凭据 | `AI_AUTH_DIR/accounts/<account-id>/credentials.enc`，AES-256-GCM；依赖原 `SESSION_SECRET` |
| 平台 API Key | 服务端环境变量；不下发浏览器 |

本地读写、搜索、输入预检、Skill 文件解析与 PDF 解析不上传资料正文。主动上传图片识别时，原图经 `/api/ocr/recognize` 临时转发至配置的 BBC_OCR 同步服务；不创建 OCR 作业或保存图片文件。主动提交学习模型任务时，浏览器才发送该任务所需的文字到 `/api/gateway/execute`，服务器临时转发并流式返回结果。正式答案、原图与完整学习数据位于用户设备，不能将浏览器的只读题目界面视为防作弊边界。网关不提供服务器学习 CRUD 接口，不接收整库同步。

浏览器复用原领域状态机、复习算法、版本检查和幂等记录。IndexedDB 严格事务提交与 revision CAS 防止覆盖其他标签页的写入；Web Locks 为同一账号和模式选出一个任务执行器，退出/切换账号会锁定其他标签页。执行中的模型请求在页面关闭或登录到期时中断，重新打开需明确重试。AI 执行需要支持 Web Locks 的安全上下文（HTTPS 或 localhost）。持久存储失败时不退回易丢失的内存库。

在「全部模块 → 本地数据与备份」可查看记录数量、申请浏览器持久存储、导出 JSON、确认导入或清空本账号当前模式的数据。JSON 未加密且包含私人原件、答案和任务快照；OAuth 凭据与云端账号密码不包含在内。账号 ID 分库是应用隔离，不是磁盘加密；同设备其他浏览器配置、其他设备或不同站点地址不会自动共享。清理网站数据可能删除本地库，持久存储权限不能代替备份。当前没有自动云同步或自动加密云备份。

旧数据迁移：

1. 停止旧 API，保留旧 `DATA_DIR` 和原授权目录。运行 `npm run data:export -- ./backup.json`；若旧物理库尚未升级，使用 `--before-migration`。
2. 使用默认 `APP_STORAGE_MODE=local-first` 启动，在页面创建账号。旧 `OWNER_PASSWORD` 不会自动成为新账号密码。
3. 在同一 mock/live 模式的「本地数据与备份」导入 JSON。导入只替换当前账号、当前浏览器、当前模式的数据；未完成任务不会自动重放。模型选择随备份保留，Provider OAuth 需为新账号重新授权。
4. 验证资料和历史记录后，自行保管导出备份。云端账号库应单独停服备份；保留稳定账号 ID 才能继续定位同一浏览器的本地库。授权目录和原 `SESSION_SECRET` 也需单独安全保管。

云端目前使用单进程嵌入式账号库，不直接支持多个 API 副本同时打开同一目录。网关按账号实施单并发、`GATEWAY_DAILY_CALLS`（默认 200 次）和可选估算预算；防重放记录跨重启保留，失败或未知用量不自动按零重试。公网实例需使用 HTTPS，并在反向代理关闭请求体/响应体记录和网关响应缓冲；上线操作由部署环境另行配置。

隔离验证：`npx playwright test --config playwright.local-first.config.ts` 使用临时账号库、全新浏览器数据和 mock 模型，不加载私人 `.env` 或用户数据。旧服务器回归仍使用默认 Playwright 配置。

### 图片上传与 OCR

在主页附件入口，或「今日复述 → 给记忆一点参考」上传/拖放 PNG、JPEG、WebP 图片。图片最大 10 MB（10,000,000 字节）、4000 万像素；PDF 单文件最大 20 MB（20,000,000 字节），文本笔记仍按原有大小限制。上传区显示读取、PDF 页数解析与保存进度；导入成功、失败或取消通过蒙版提醒，可重新选择同一个文件重试。PDF 仍限制 100 页、200,000 字符，与文件体积独立；超限分别显示实际页数，或触发文字上限的页码和已提取字符数，不静默截断原文。图片提交后先识别并显示原图与文字，用户可修改识别结果，再点击「确认导入图片资料」。确认前不写学习资料，取消不会添加图片；识别失败可保留原图重试。OCR 不调用学习模型，在 mock/live 下都使用配置的识别服务。

默认本地优先模式把原图、校对文字、OCR 模型信息和核对状态保存到当前账号当前浏览器，支持原图预览/下载、检索和学习备份恢复。原图不会直接发送给学习模型，学习任务按原有来源选择和输入预算使用已确认的文字。扫描 PDF 仍需先导出为图片再上传。

复用独立的 **BBC_OCR** 项目，以同步 `POST /v1/recognize` 接口识别，不使用磁盘作业接口。API 端 `.env` 配置：

```dotenv
OCR_SERVICE_URL=http://127.0.0.1:8000
OCR_SERVICE_TOKEN=
OCR_TIMEOUT_MS=120000
BBC_OCR_PROJECT_PATH=../BBC_OCR
BBC_OCR_PYTHON=/path/to/your/ocr-environment/bin/python
```

`OCR_SERVICE_TOKEN` 仅由 API 转发为上游 Bearer 令牌；不进浏览器或学习备份。可选 `BBC_OCR_CONFIG` 指定已有 YAML 配置。你的本机配置使用现有 `/home/shi/miniconda3/envs/bbc-ocr/bin/python` 环境和 `BBC_OCR` 中的配置及缓存模型。

- `npm run dev:ocr`：一起启动现有 BBC_OCR、API 和网页。
- `npm run ocr`：只启动本机 BBC_OCR；已有 OCR 服务时按原方式启动应用。
- 已在其他主机运行 BBC_OCR 时，只需配置 `OCR_SERVICE_URL` 与令牌，不用本机启动脚本。

本机启动脚本使用 `--no-jobs`，只监听回环地址，不向兄弟仓库写入 Python 字节码或创建作业库。每账号同时最多一个 OCR 请求，全站同时最多两个，每账号 15 分钟最多 30 次；取消等待会中止本页请求，已开始的引擎推理可能继续到结束，但不会保存到学习资料。识别文字最多 200000 字，超过限制需裁剪或拆分图片。

### 管理后台与平台 AI

默认本地优先模式提供 `/admin` 管理后台，使用与学习端一致的主题。首次绑定时，在 `.env` 配置 `ADMIN_USERNAMES=admin` 并重启 API；只提升启动前已经注册且启用的同名账号，保留其原密码。已有启用的管理员后，该环境变量不再提升其他账号，后续权限通过后台管理。不要将未注册的用户名当作已预留管理员。

使用管理员账号登录，从「全部模块 → 管理后台」进入。后台包含真实账号/活动/调用统计、用户搜索与创建、停用与启用、密码重置、管理员权限和每日额度管理，以及管理操作记录。普通用户不能读取管理接口；权限、状态或密码变更立即撤销目标账号会话。云端看不到用户本地学习库中的笔记与学习进度。

在「平台 AI」选择服务名称、Provider、模型并保存 API key，可设置每用户每日次数、全站每日次数与平台并发上限。API key 加密保存，不回显、不进入学习备份，保存不发测试请求。`MODEL_API_KEY` 在本地优先模式仅作为同 Provider 的平台密钥回退，个人模型不能借用平台密钥；个人授权继续按账号隔离。更换 `SESSION_SECRET` 前需保管原密钥，否则已保存的平台密钥和个人 OAuth 凭据需重新配置。

用户进入「AI 配置 → AI 服务来源 → 使用平台 AI」并保存，随后主动发起的新任务才使用平台 AI。默认不替用户选择服务。禁用平台、撤销账号平台权限或用完额度后，新平台任务会被拒绝；失败与中断也计入次数，按配置时区的自然日累计。mock 中平台选择仅验证流程，任务仍是模拟回答。

「服务器」展示当前 API 主机 CPU、内存、系统负载、API 进程内存、事件循环延迟、会话与模型请求数。每 10 秒真实采样，内存中最多保留 30 分钟，重启后重新积累。当前只监测单个 API 实例；多实例聚合、磁盘/网络指标、持久指标和告警尚未接入。

## 代码题与浏览器运行器

在「复习计划 → 学习、复习与缓存设置」开启「代码题」，选择至少一种语言并确认保存。默认关闭，默认语言 Python。开启后 AI 判断知识点是否适合代码题，与单选/简答混合；mock 固定将最后一题设为所选第一种语言的演示题。

代码题带中文注释骨架与可见测试。在编辑器中完成 TODO，点击「运行测试」查看逐条结果和输出，再「正式提交」。可以不运行直接提交；最终评价由模型按评分细则给出，浏览器报告只作不可信辅助证据。修改代码会清空旧结果；「重置为骨架」需确认，主动清空并暂存后不会自动填回骨架。TypeScript 仅去除类型标注，不做类型检查。

```sh
# npm ci 后；开发、构建、启动、setup 和 e2e 会自动生成核心文件
npm run code-runner:build
# Python 科学计算的一次性准备（必须在完整 e2e 前完成）
npm run code-runner:packages
```

固定 Pyodide 314.0.7，包含 numpy、scipy、scikit-learn 及 joblib/threadpoolctl 依赖。下载脚本只访问同版 Pyodide 官方发布目录，逐份核验锁文件 SHA-256；已校验的文件可复用。全部运行时本地托管，运行期间不依赖 CDN；缺包会显示上述安装命令，Python E2E 缺包会失败，不会跳过。生成文件位于被 git 忽略的 `apps/web/public/code-runner/`，不要手工编辑；新机器或删除生成目录后重新执行准备命令。生产 start 同样先用 esbuild 生成，安装时需要保留开发依赖。

代码只在浏览器的不透明源 sandbox iframe + Worker 内执行，本地优先模式将代码和评价保存在此浏览器，正式提交时才向 AI 网关发送本题所需内容。准备运行时限 90 秒、执行限 10 秒，父页面另有 105 秒硬超时；输出最多 4,000 字符。Python 保留已加载 WASM/科学包以加快重复运行，每次作答使用新变量作用域。JS/TS 可使用 `assert`、`assertEqual`（深比较）、`assertClose`，不支持 npm 模块导入。Python 范围为内置标准库及上述科学包；不支持任意 pip 安装。

旧页面遇到代码题提交提示时刷新即可；单选/简答和旧偏好请求仍兼容。隔离、缓存与资源限制见 [ADR 0004](./docs/decisions/0004-代码题与浏览器沙箱运行器.md)。

### 旧服务器模式的存储、执行与读取边界

本节描述显式 `APP_STORAGE_MODE=server` 的兼容实现；默认模式见下文「本地优先存储与迁移」。

以下改造已通过离线回归，接口约定与剩余限制见状态表。

- 资料/测验详情、设置及相关查询按所需实体或字段读取，继续由同一事务队列观察已提交状态；统计在单次请求内复用时区格式化器。完整状态、导出和写事务仍有全量成本，搜索的 BM25 扫描也未消除。测量入口为 `npm run benchmark:reads -- /tmp/new-read-report.json`，详见[存储性能边界](./packages/database/README.md#工程边界与剩余成本)。
- **PGlite 单进程嵌入式 PostgreSQL + Drizzle**：物理 schema v4 将资料原文拆到 `app_documents`、AI 任务输入拆到 `app_run_tasks`，测验及证据正文拆到 `app_learning_records`，其余业务仍是聚合；进程内快照缓存、串行事务与 revision CAS。不是全部实体拆表，仍受聚合内存和全聚合写校验成本限制，不能直接横向扩容。
- 工程目标：单用户 **≤1,000 知识点 / ≤500 资料 / ≤1 年日常记录**，已使用合成容量样例测量，仍是非强制观察目标而非性能保证（见 ADR 0007）。超过后观察逻辑 JSON 导出体积与读写延迟，再拆更多实体；PGlite 磁盘目录有固定开销，39M 不能证明逻辑数据体量，也不能据此断言几个月必慢。
- 入队后唤醒单执行器，不做空闲轮询或多 worker 租约。持久化 run/attempt 与版本检查仍用于阻止取消后的迟到结果。
- 客户端没有 SSE 消费；本轮直接移除旧 SSE。`GET /api/state?since=revision` 返回 `unchanged`、`snapshot` 或 `delta`（`upsert/remove`），仅保留 16 个指纹基线，未知 revision 回快照。Web 使用 `compact=1` 首载摘要，已交卷测验详情及分页证据按需读取；其他实体仍全量同步；资料全文登录后通过 `GET /api/documents/:id` 按需读取，首次状态不带全文。`/api/me` 仅读取内存中的小型设置投影，不读取 SQL 或复制全量聚合；不承诺所有 OAuth/连接测试查询都无轮询。
- 同一数据库目录只能由一个应用进程打开；API 和维护脚本也不能同时打开。合作进程之间有文件锁；只自动回收可确认已退出的本机 PID 的锁。未知/损坏锁或恢复锁失败关闭，不要直接删除正在使用的锁。
- Agent 使用**无工具的、单次结构化输出任务**，输出须通过严格 Schema、引用与状态检查，再由宿主提交。没有赋予模型文件系统、数据库或命令执行工具。
- PGlite 目录仅供本应用管理；不要绕过进程锁直接用另一 PGlite 实例打开，也不要在线复制目录作为一致性备份。

### 输入与资料预算

数值唯一来源是 [`packages/contracts/src/limits.ts`](./packages/contracts/src/limits.ts) 的 `LIMITS`：三字段各 20,000 字符、主题 80、答案/理解/回忆各 12,000；任务 JSON 48,000 字符；文本笔记上传默认每文件 131,072 bytes，配置最大 1,048,576 bytes；PDF 最大 20,000,000 bytes、图片最大 10,000,000 bytes，资料默认每份复述 5 个、配置最多 10 个；追问默认 3 最大 5，题量默认 3 最大 5。文本型 PDF 还受独立的 100 页、200,000 字符和 15 秒解析限制。

上传是**存档预算**，不是每次全量外发承诺。仅已确认来源会外发：放得下就全文发送；超出剩余预算才做本地分块/BM25 检索，按实际空间选取片段，带行号与省略标记；无命中时标明有限首尾背景。追问与会话测验共用一套稳定来源以利于厂商前缀缓存，问答过长时先省略较早作答，完整问答仍存档。然后执行 H2 预算；正式答案和 rubric 不截断。原文始终保留，不把‘检索片段预算足够’说成全文阅读。没有 embedding 费用或额外摘要请求，词面检索也不保证语义覆盖。见 [ADR 0002](./docs/decisions/0002-本地检索与显式知识关联.md) 与 [ADR 0003](./docs/decisions/0003-全文优先-稳定前缀与自动旧知识联想.md)。

复习计划现在支持连续复习、单卡暂停/恢复，以及按 7/30/90 天或全部记录查看独立表现、常见失分项、待核对记录和未来 7 天负担。各项可追溯至原题，演示数据单列；原评级规则和历史排期不变。连续队列仅保存在当前标签页，退出登录清除。见 [ADR 0006](./docs/decisions/0006-文本PDF与复习统计.md)。

live 同时按所选模型目录的上下文窗口校验：完整系统提示、当前任务输出 Schema 和用户任务 JSON 的 UTF-8 字节数作**保守 token 估算**，另留配置的输出额度及 512-token 消息适配余量。不是精确分词，也不保证厂商接受、OAuth 输出硬上限或费用。必要内容放不下时明确拒绝，grade 不截正式答案或 rubric。

复述与简答页面通过鉴权的服务端预检，包含已上传资料/私有评分标准，仅返回计数及节选条目，不把原文或答案返回预览。预检不写库、不创建任务、不访问模型或刷新凭据；提交与执行仍重新检查。预览失败或过期不能继续用旧余额，草稿保存和明确跳过不受影响。完整语义见[稳定规格](./docs/产品与架构规格.md#3-统一限制与外发范围)。

## 数据管理

### 物理 schema v4 升级（临时库验证通过）

1. 先停止所有占用该数据库的服务。在启动新版前运行 `npm run data:export -- ./backup-before-v4.json --before-migration`：此专用路径兼容已有物理 v1/v2/v3/v4 目录，加锁后在 SQL 只读事务中完整导出，不初始化或升级 schema；不需要找回旧程序。安全保存备份并核对可恢复性。
2. 新版对旧物理 v1/v2/v3 执行事务升级，资料原文进入 `app_documents`、任务输入进入 `app_run_tasks`；测验及证据进入 `app_learning_records`，全新库按 v4 建立。不要并行打开或在线复制运行中的数据库。
3. **AppData JSON 备份的 `schemaVersion` 仍为 1**，不随物理 schema 改为 4。新物理库不支持旧程序直接打开；回退须使用升级前备份恢复到兼容环境，不原地降级。

临时 v1 CLI 测试已验证导出后物理 schema 仍为 1、文件权限 `0600` 及 `wx` 拒绝覆盖。本轮不操作用户数据，不声称已替用户完成备份或真实数据库迁移。`--before-migration` 仍需独占锁，PGlite 启动可能执行自身 WAL 恢复，不承诺磁盘零写；导出 JSON 为未加密私人资料，权限 `0600` 且不覆盖已有文件。

### 日常维护

先停止 `npm run dev` 或 API，确认没有进程占用同一数据库目录。命令按 `.env` 中的 `AI_MODE` / `DATA_DIR` 操作，**不调用模型**。

```sh
npm run db:migrate
npm run data:export -- ./backup.json
npm run data:import -- ./backup.json --confirm
npm run data:delete -- --confirm
```

- 导出包含全部笔记、原文、内部答案、任务记录及非敏感模型选择，为**未加密的私人 JSON**，新文件权限 `0600`；已有文件不会覆盖。OAuth 凭据不在学习数据库及此备份内；清空会移除保存的模型选择，但不会断开 Provider。
- 恢复覆盖当前逻辑数据，先备份；拒绝不兼容版本、结构损坏或不同 mock/live 模式，导入上限 256 MiB。不声称验证了所有业务引用关系。
- 恢复后的未完成请求标记失败，需显式重试；不会重放可能已收费的请求。备份之后发生的收费不会因恢复旧备份而消失，应用账本不能代替厂商账单/额度限制。
- 学习记录、证据和原文不自动到期，由用户手动导出/清空。已知的 CAS 草稿/理解/回忆暂存回执在后续新命令中按 24h、最多 2,000 条清理，不运行额外定时写库；含 `runId` 的任务/连接测试、未知操作及其他非暂存收据长期保留；不是所有非计费命令都自动清理，也不能靠旧备份保证永久去重。
- 清空是逻辑删除，不承诺对磁盘/WAL 安全擦除，不删除其他备份，也不撤回厂商已收到的数据。需要物理清理时，停止服务后清理对应数据目录和自行保存的备份。手动清空或恢复旧备份不能保留被移除的防重放记录。
- 崩溃后通常可自动回收过期锁；若提示未知锁，请先核对 `.sanxing.lock` 的主机/PID、确认所有 API 与维护进程已退出，再手工处理该目录内的 `.sanxing.lock` / `.sanxing-recovery.lock`。不要在运行中移除锁。

## AI 配置、OAuth 与 token 热力图

登录后从右上角「全部模块」进入 **AI 配置**，地址 `/ai-access`。本站密码登录与厂商授权是两套独立身份；授权不自动切换 live 或选择模型。模型选择、OAuth、热力图独立取数，读取或保存配置不发送模型测试请求。授权区默认仅列已保存 OAuth 凭据的 Provider；“添加授权”按需展示其他厂商，授权帮助也随流程展开，不会因此删除已有凭据。

| 本应用 Provider | 当前接入方式与注意事项 |
|---|---|
| `anthropic` | Pi 原生 OAuth；可选 browser 或 copy_code，后者无需本地回调监听 |
| `openai` | Pi 的 ChatGPT OAuth；固定监听 `127.0.0.1:1455`，也可按提示粘贴完整最终回调 URL |
| `openai-codex` | Pi legacy Codex OAuth；可选 browser 或 device_code；身份不与 `openai` 混用 |
| `xai` | Pi 原生 xAI OAuth（SuperGrok / X Premium 订阅，与 Grok Build 同一授权）；仅设备码登录，无需本地回调；也可用服务端 `MODEL_PROVIDER=xai` + `MODEL_API_KEY`；请求保留 `max_output_tokens` |

Pi 本身还有其他 OAuth Provider，但本应用只显式注册以上四项。OAuth 不保证免费，也不绕过会员、账号权限或厂商使用政策；授权页可能显示 Pi 客户端名称。

- **WSL**：能访问网页 3010 不代表 Windows 能访问 WSL 的 OAuth 回调端口。优先按厂商提供的 copy_code / device_code 选项操作；OpenAI 回调无法打开时，按页面提示复制地址栏完整 URL（含原参数），不要只摘取 code，不要提交到第三方网站。
- 授权会话最多 10 分钟，且不能超过本站登录有效期；最多一个正在进行的流程。取消、到期、登出及关闭服务阻止迟到授权再次存储。离开页面停止轮询并清空输入，不会自动重新发起授权；可回到页面继续尚未到期的流程。
- 凭据仅保存在服务端专用目录 `data/ai-auth`（可用 `AI_AUTH_DIR` 更改），不读取 `~/.pi` / `~/.codex`。磁盘使用 AES-256-GCM、私有权限、原子替换及进程锁；完整 refresh token 和扩展字段由 Pi 在串行 `CredentialStore.modify` 中刷新。加密不等于进程隔离。
- 凭据加密密钥由 **`SESSION_SECRET` 派生**：必须保留原值；直接更换会导致已有凭据无法解密，应用会失败关闭，不静默清空。迁移凭据时，停服务后单独安全备份授权目录及原密钥；它们不属于普通学习 JSON 导出。
- 「已连接」仅表示本地已保存凭据，不是上游账号实时验证。令牌到期后由 Pi 在调用时尝试刷新。断开仅删除本应用凭据，不等于厂商撤销；已开始的执行可能继续，必要时在厂商账号设置撤销授权。每个应用账号下的每 Provider 只有一份连接，任务在执行时读取该账号的当前凭据；重新授权前应停止在途/排队真实任务，未把排队任务绑定到 Provider 授权变更前的旧厂商账号。
- 热力图按配置时区的任务开始日统计，支持年度切换、输入/输出/总 token、未知用量标记。输入已包含缓存，不重复累加；另显示年度已观测缓存读/写 tokens，旧记录缺计数时标未知；失败或取消中观测到的用量也保留，未知不能视为零。执行次数是已开始的任务尝试，不保证已发出上游请求；排队未开始及预算拒绝不计入。
- mock / live 统计隔离；mock 是 faux 演示估计。已知总数不含未知部分，历史缺失不能补造；不是厂商全账户用量、订阅剩余额度或账单，也不是 OAuth access token 字符串长度。

HTTP WSL 访问仅适合可信本机/网络；授权码也需要传输保护，公网必须使用 HTTPS。真实授权、刷新及账号权限仍需你在选定厂商后自行验证；自动测试均使用离线假 Provider，不替你授权账号。

### 手动连接测试

在已连接 Provider 上点击“测试连接”，须先保存该 Provider 的 **OAuth 模型**并启用 **live**。确认弹窗说明测试对象与费用/额度风险后，才发送一次固定最小请求；不携带复述、笔记或答案，不创建学习会话/知识点，也不把 mock/faux 当作真实连通。

- 使用相同 Pi Provider、OAuth 刷新和任务工作器；入队、执行分别核对保存的选择，防止测试期间悄悄换模型。默认没有应用金额预算；若显式配置预算，连接测试同样受其约束。
- 应用请求参数/事后校验至多 256 输出 tokens、执行阶段超时至多 30 秒（已有更小配置优先），**OpenAI/Codex OAuth 仍无上游输出硬上限**。所有测试至少间隔 30 秒，不与既有 pending/running 任务抢占。
- 测试任务与幂等收据持久化；失败、取消或重启后不会自动重发，通用学习重试入口不重放测试。取消不能保证厂商停止计费，离开页面只停止查询；后续测试须重新显式确认。
- 显示本次结果、模型、时间、耗时、已知或未知 token；已观测用量纳入热力图，失败也保留。成功只证明该模型在该时间的一次最小请求成功，不保证持续可用或学习评价质量。

## 真实模型：显式选择，尚未实测

API key 支持 **OpenAI / Anthropic**；OAuth 支持上表三个 Provider。按当前自用需求，**默认不设应用金额预算**。不设预算不等于免费、无限订阅额度或厂商硬限额；真实任务会向所选厂商发送任务资料，可能产生费用或扣减额度。

1. 根 `.env` 设置 `AI_MODE=live` 后重启。可以不填模型和预算：API、登录与配置页面正常启动，未配置时仅阻止提交模型任务，保留已保存的复述。
2. 进入 **AI 配置**，完成所需 OAuth 授权（已有连接无需重复授权）。自行选择 **Provider → 认证方式 → 模型**；目录来自已安装 Pi 的本地显式 Provider，不是账号权限查询，也不自动选第一项。
3. **OpenAI / Codex OAuth** 当前不发送上游输出 token 硬上限。保存模型时页面按认证能力记录此选择，不再额外显示勾选框；事后输出校验不能追回消耗。
4. 保存立即影响随后发起的新任务，无须为换模型重启，不会发送测试请求。存在 pending/running 任务时拒绝切换；版本冲突保留输入，须显式刷新配置再确认。

AI 配置中的「模型与授权」统一展示模型选择和 Provider 授权；桌面并排、手机纵向排列，保存成功后显示蒙版提醒，失败保留输入并说明原因。上传、授权、Skill、设置、备份及后台的操作提醒采用相同蒙版样式：相同消息去重，不同消息依次显示；支持「知道了」、Escape 和点击蒙版关闭，恢复焦点与页面滚动，嵌套提醒只锁定最上层窗口。加载与导入进度继续在操作区域展示。默认选择保存在此浏览器、此账号当前模式的学习数据库，重启保留并随学习备份；mock/live 分别保存。mock 中保存仅为候选配置，任务始终使用 faux，页面不能热切数据模式。本地优先模式要求用户自行选择模型；旧服务器模式中，保存的选择优先于 `MODEL_PROVIDER` + `MODEL_ID` 环境回退。

API key 不在浏览器输入：在服务端配置匹配的 `MODEL_PROVIDER`、`MODEL_AUTH_METHOD=api_key`、`MODEL_API_KEY`，重启后在页面选择该厂商和模型。OAuth 执行只使用应用 CredentialStore，不使用或回退到此密钥。使用旧环境变量直接配置 OAuth 时，应设置 `MODEL_AUTH_METHOD=oauth`、移除 `MODEL_API_KEY`；OpenAI/Codex 还需显式的 `AI_ALLOW_UNBOUNDED_OAUTH_OUTPUT=true`。

不设预算时，省略 `AI_BUDGET_PER_USER_DAY` 与 `AI_REQUEST_RESERVATION_USD`，不会因美元额度拒绝任务。若以后需要应用估算预算，须同时填入两个正数；仍不能替代厂商硬限额。若当天已有未预留的未知费用，启用预算后不会把它计为免费，会暂停新模型任务，需核对策略或等待下一预算日。token、已知费用与未知计量继续记录，超时、任务次数、输出校验等限制不变。真实复习排期仍独立控制，默认 `REVIEW_SCHEDULING_ENABLED=false`。

- 配置以 [`.env.example`](./.env.example) 与 [`apps/api/src/config.ts`](./apps/api/src/config.ts) 为实现来源，不从历史手册复制未实现变量。不支持自定义端点（`MODEL_BASE_URL` 设置后拒绝启动）、个人 Pi CLI 凭据或任意 Provider，不静默降级。
- 默认最多 3 轮追问、3 题、每会话 20 次模型任务；可配置项见 [`.env.example`](./.env.example)。输出校验默认 4096 token；普通任务总时限默认 60 秒（`AI_RUN_TIMEOUT_MS`），测验默认 120 秒（`AI_QUIZ_TIMEOUT_MS`），连接诊断最多 30 秒。首响应等待默认 60 秒（`AI_FIRST_RESPONSE_TIMEOUT_MS`），流停滞默认 45 秒（`AI_STREAM_IDLE_TIMEOUT_MS`）；各配置最大 120 秒，阶段计时不会延长任务总时限。不自动重试模型请求；上游输出限制受上述 OAuth 差异约束。
- 新任务保存提示词版本与系统提示、Schema、实际用户输入块的 SHA-256 指纹。执行前核对；升级后不匹配或缺少指纹的旧排队任务标记失败、保留输入，需手动重试以创建使用当前提示词的新任务。历史记录不补造指纹，运行中断的请求仍不自动重放。
- 页面显示准备请求、等待响应、生成、校验、保存阶段，以及已用时间和最近收到内容的时间。只有非空文本/思考片段重置流停滞计时；首响应指 HTTP 响应头或首个内容片段，不等同于首字。保存用量和业务结果不占模型时限。运行中进度通过独立内存接口每秒读取，不随 token 写数据库；结束后保存相对阶段时间，旧记录不补造。不会向浏览器发送原始模型流、推理或未作答题的答案。
- 任务保留经过筛选的错误码，并显示限流、授权、超时、响应校验等对应提示；主动取消与服务中断单独记录。Provider 原始错误、响应正文和堆栈不会进入任务错误记录，已观测用量继续保留。
- SDK 流失败进一步区分 DNS/TLS、网络连接、OAuth 刷新或存储、上游流错误、额度及提前断流。Codex 的 CRLF/CR 换行按块兼容，未收到明确完成终态不会提交学习结果；不自动重试，不通过关闭 TLS 验证处理网络错误。
- 连接诊断保留白名单原始错误码、传输阶段、实际 socket 复用和收发字节增量；缺失观察保持未知。`AI_CONNECTION_POLICY=pooled` 默认复用有空闲上限的独立模型连接池，`fresh` 每任务新建连接。合成评估可用 `--connection-policy pooled|fresh` 对照，无自动重试；详见[连接诊断说明](./docs/evaluations/README.md#连接诊断与对照报告-v32026-10-23)。
- 评估报告记录阶段耗时、SDK 请求配置、输入大小、输出 token、缓存计量与失败分布，按任务/模型给出 p50/p95 和有效样本数；未知项不填零。执行仅检查所选 Provider 授权，静态模型目录按进程复用，用量重复交付不重复提交；设置、待执行判断和单条评估查询采用小范围读取。测量方法和结果见 [评估说明](./docs/evaluations/README.md)。
- 费用是 Pi 目录估算，不是账单；本轮有效结果即使用量未知也可成功，计量保留 `null` / 未知，仅在启用预算时保留对应预留（已通过离线回归）。未知不当成免费。取消不能保证上游停止计费，保守预留无法替代厂商侧硬限额。
- 启动前清理宿主的厂商密钥/代理/TLS 覆盖环境变量。独立 AuthContext 不等于 OS 沙箱；严格隔离应使用净化的独立进程。细节见 [`packages/learning-agent/README.md`](./packages/learning-agent/README.md)。
- 不会在日志或浏览器 DTO 中发送模型密钥。启用 live 会向所选厂商发送本次任务所需的复述、选定资料、问题与作答；不是“所有资料都只留在本机”。

### 导入学习 Skill

在 **AI 配置 → 学习 Skill** 选择本地 UTF-8 `SKILL.md`，预览后确认导入，再选择适用的知识提取、追问、出题或评分任务并启用。页面可下载示例文件，也支持查看、停用、删除及同名文件更新；更新后需重新启用。导入本身不调用模型。

文件采用 [Agent Skills 的 YAML frontmatter + Markdown 格式](https://agentskills.io/specification)，至少包含 `name`、`description` 和非空指令正文。支持单独 `SKILL.md` 或 ZIP、7Z、TAR、TAR.GZ、TGZ 压缩包。压缩包在浏览器本地 Worker 中解包，不上传原包；可分别预览并导入包内多个 Skill。单包最大 10 MiB、256 个条目、展开合计 20 MiB；拒绝加密包、链接和不安全路径。SKILL.md 最大 32 KiB、正文 16000 字，每个 Skill 可附带最多 8 份 UTF-8 参考文本（Markdown、TXT、JSON、YAML、CSV），合计最多 8000 字。附带脚本及二进制文件不导入或执行，不执行 `allowed-tools`。按 mock/live 分开保存，最多保存 20 个，每次任务最多选择 3 个，指令与参考文本合计不超过 24000 字。模拟模式可验证管理流程，模拟回复不会体现指令效果。

启用只表示加入可选列表，不会自动调用。用户在知识提取、范围确认后的追问、下一轮追问、出题、评分或模型复评前，通过 Skill 下拉框明确选择本次使用的项目；默认不使用，不自动继承到下一步骤。提交时核对所选版本与适用任务，变更后需刷新选择。仅将本次选中的指令与参考文本发送给所选模型；完整内容计入上下文预算，超预算不会静默截断指令。排队时冻结版本和正文，并纳入提示词指纹；修改或删除不影响已排队任务及其明确重试。连接测试和基线质量评估不使用个人 Skill。固定输出格式、评分标准、知识范围及单次请求约束继续生效。

### 云 Skill 目录

在根 `.env` 配置 `SKILL_CATALOG_URL` 后重启 API，例如 `https://your-server.example/skills/catalog.json`。若服务器需要认证，可同时配置 `SKILL_CATALOG_TOKEN`；Bearer 凭据仅由服务端使用。登录后打开 **AI 配置 → 学习 Skill → 云 Skill**，即可搜索远程列表并「下载到本地」。默认下载结果保存在此账号、此浏览器当前模式的学习数据库中，默认停用，可在「本地 Skill」查看、选择任务和启用，也会随学习数据备份。未配置来源时显示空状态，不请求外部服务器。

目录服务器返回以下 JSON；`version` 和 `author` 可省略。文件 URL 可相对目录解析，必须位于同一服务器、同一目录或其子目录内，不跟随重定向。

```json
{
  "skills": [
    {
      "name": "explain-with-examples",
      "description": "使用具体例子帮助理解知识点",
      "version": "1.0.0",
      "author": "我的教学方法库",
      "url": "explain-with-examples/SKILL.md"
    }
  ]
}
```

远程 `SKILL.md` 使用与本地导入相同的格式和限制，文件内 `name` 必须与目录匹配。目录最多 100 项、256 KiB，单次读取超时 10 秒，Skill 文件最多 32 KiB；下载不执行脚本、不调用模型、不覆盖同名本地 Skill。云 Skill 下载及本地 Skill 管理沿用本站登录、CSRF、幂等和版本保护。

### 可选提示缓存

复习页“复习与缓存设置”可选择 `short`；默认仍为 `none`，不会擅自修改现有偏好。设置与学习数据按 mock/live 隔离持久化，不修改 `.env`；保存需要明确确认、版本检查，活动任务期间禁止更改。每任务仍独立 Agent、单次请求、零自动重试。稳定内容尽量前置，以服务端 HMAC 生成会话亲和键，连接测试不请求缓存。

缓存不是免发资料或免费额度，不保证命中、TTL、节省金额或输出硬上限；`none` 也不能保证厂商完全不缓存。开启短缓存时，Anthropic 只在追问/会话测验的稳定资料块上放一个断点；OpenAI 依赖自动前缀缓存与会话亲和键；Codex OAuth 与 xAI（Grok，API key 或订阅授权）同样依赖自动前缀缓存与亲和键 `prompt_cache_key`（无显式断点；xAI 命中部分约 0.25 倍计费），上游若报告缓存读取 token 会照实记录，但订阅额度下节省无法换算成金额。计量以实际报告为准，不依据开关猜测费用。具体厂商差异见 [ADR 0002](./docs/decisions/0002-本地检索与显式知识关联.md) 与 [ADR 0003](./docs/decisions/0003-全文优先-稳定前缀与自动旧知识联想.md)。

### 复习排期

模拟环境使用 `ts-fsrs@5.4.2` 默认权重、目标保留率 0.9，关闭 fuzz 与短期学习，以实际独立作答时间计算，并单独标记模拟事件。真实环境需接受实现、参数、时区及评级映射后，在复习页展开“复习与缓存设置”并明确保存。未保存应用偏好时继承 `REVIEW_SCHEDULING_ENABLED`（live 默认 false）；**关闭时不开新卡、不排期，也不推进既有卡片**，但允许完成已交卷复习并保留证据。启用不自动补历史卡；知识详情可单点明确加入复习，不调用模型。

排期启用时，初始卡在学习测验交卷后创建，到期时间暂设为 24 小时后，仅是复习提醒，不代表掌握。当前 `mapping-v1` 只聚合已评价、未受辅助、未跳过的作答：任一参与作答未满分则 Again，全部满分才允许用户选择评级。同一测验同目标的后续题因前题已展示解析，会自动标记辅助并排除；无有效独立作答则不排期，待核对/跳过不冒充答错。具体规则见 [`packages/learning-domain/src/service.ts`](./packages/learning-domain/src/service.ts)，尚未经过长期学习效果验证。

## 自动化验证与失败诊断

本地和 [GitHub Actions](./.github/workflows/verify.yml) 共用以下入口，使用模拟 Provider、合成数据及隔离的测试服务。无需运行 `setup` 或配置模型凭据：

```sh
npm ci
npx playwright install --with-deps chromium
npm run verify
```

`npm run verify -- --suite core` 运行边界/类型检查、验证脚本自测、全量 Vitest、HTTP 代理测试和 30 个离线评估样例；`--suite browser` 校验或下载锁定的 Python 科学计算包，运行旧服务器及本地优先两套 Chromium 回归与隔离生产构建。默认依次运行两组，本机请勿同时启动多个 browser 验证。首次安装浏览器及 Python 包需要网络，测试中的模型调用保持离线。安装方式遵循 [Playwright CI 文档](https://playwright.dev/docs/ci-intro)。

每次验证创建独立的 `artifacts/verify-*/`：`summary.json` 记录各步骤状态、耗时、退出码及日志路径，另保留 Vitest JSON、离线评估报告、Playwright HTML/JSON 和失败 trace。失败立即返回非零退出码，后续步骤标记 `not_run`；中断标记 `cancelled`，不会自动重试或当作通过。定位时先看 summary，再看对应 `.log`；浏览器详情可用 `npx playwright show-report <目录>/playwright` 或 `npx playwright show-trace <trace.zip>`。报告不主动采集环境变量或个人数据库；测试日志及 trace 仍应按其实际内容分享。

浏览器验证沿用 3027/4107 独立端口及 `.next-e2e` / `.next-validation`，结束后恢复原 `next-env.d.ts`。CI 的 core/browser 两个任务独立执行，即使一组失败也保留另一组结果；禁止 `.only`，失败不自动重跑，报告保留 7 天。工作流固定 Node 22.23.2、npm 12.0.2 和 Actions 提交，不加载个人配置、不部署。提交到 GitHub 后才会触发远端运行；是否设为合并必需检查由仓库分支规则决定。

可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chrome` 指定已有 Chromium。各批次实际验证结果见[审查修复记录](./docs/审查修复记录.md)，历史 Markdown 回归见[实施结果](./docs/笔记Markdown渲染-实施结果.md)；真实模型质量与账号评估另见[评估说明](./docs/evaluations/README.md)。自动化结果不替代 Windows→WSL 人工网络验收或长期学习效果评估。
