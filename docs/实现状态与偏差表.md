### H3：存储、执行与读取

| 层面 | 离线验证结果 | 保留边界 |
|---|---|---|
| 物理存储 | schema v3 将文档原文拆到 `app_documents`、任务输入拆到 `app_run_tasks`；新库、旧 v1/v2 事务升级、失败回滚、全文一致性、未变化不写通过 | 其他业务仍聚合，不是全面规范化 |
| 逻辑备份 | AppData JSON `schemaVersion` 仍 1；完整导入导出保留原文 | 不把物理版本当备份版本；导出未加密，vault 不在其中 |
| 升级前导出 | `npm run data:export -- ./backup-before-v3.json --before-migration` 支持已有物理 v1/v2/v3；加锁、SQL 只读事务、完整导出，不初始化/升级 | 临时 v1 CLI 验证导出后 schema 仍 1、0600、wx；PGlite 可自身 WAL 恢复，不承诺磁盘零写；不需找旧程序 |
| 读写 | 快照缓存隔离、串行事务、revision CAS、失败/恢复、并发冲突通过 | 仍有全聚合内存及写校验成本 |
| 执行器 | 入队唤醒单执行器，移除空闲周期读取与写后历史取消扫描；取消/恢复回归通过 | 不做多 worker 租约，不重放可能已收费的调用 |
| 回执 | 仅已知 CAS 草稿/理解/回忆暂存按 24h / 最多 2,000 条，在后续新命令中清理 | 不是所有非计费 command 都删；含 runId、未知操作及其他非暂存收据长期保留；旧备份不能保证永久去重 |
| 状态读取 | `GET /api/state?since=revision` 返回 unchanged/snapshot/delta（upsert/remove）；客户端增量应用通过 | 16 个指纹基线，未知 revision 回快照；初载仍全部公共实体（资料仅 metadata），不是分页 |
| 资料全文 | 登录后 `GET /api/documents/:id` 按需读取，首次状态不带全文；`/api/me` 仅读内存小型设置投影，不查 SQL/克隆全量聚合 | 不代表所有业务已改为分页读取 |
| 轮询 | 移除未消费的旧 SSE 和空闲 worker 轮询 | 活动任务、OAuth/连接测试按需查询仍可存在，不承诺零轮询 |

本轮没有打开、检查或迁移用户真实数据库。升级前由用户停服并使用上述 `--before-migration` 命令备份；新物理库不能由旧程序直接打开，不原地降级。学习清空不删除独立 vault 或旧备份/WAL。

## 2. 有意偏离

| 旧草案方向 | 当前决定 / 理由 |
|---|---|
| tools / `propose_*` | 无工具、一次结构化输出，由宿主校验并提交；不赋予模型文件/SQL/Shell 工具 |
| worker 租约、集群接管 | 单用户单进程单执行器；保留 run/attempt fencing，避免无消费者的分布式机制 |
| SSE / 模型文本流 | 无客户端 SSE 消费，采用版本/增量读取与按需全文 |
| 全实体规范化 | 文档原文先拆表，其他聚合暂留；仅按真实热点继续拆分 |
| 默认金额预算 | 当前明确不设置；保留可选预算、未知计量、超时/任务上限与费用提示 |
| 单用户可省鉴权 | 身份、归属、CSRF、Origin 防不同风险，明确保留 |
| 历史环境变量 | 仅以 `.env.example` / `apps/api/src/config.ts` 为实现来源；`MODEL_BASE_URL` 仍拒绝 |

工程目标为单用户 ≤1,000 知识点 / ≤500 资料 / ≤1 年日常记录，属**非强制、未经大库压测保证的观察目标**。超过后观察逻辑导出体积与延迟，不自动删除学习记录、证据或原文。PGlite 39M 目录有固定开销，不能据此推断逻辑体量或性能。

- 真实数据库备份/迁移/清空、锁和服务操作本轮均未执行。3010/4000 无监听仅为当时检查结果，不替代维护前核对。
- 公网未做部署安全审计；生产 HTTPS 需独立受控部署，不扩大代理信任。真实模型、真实排期与公网部署各有独立门槛。

## 4. 最终验证摘要

`npm run check` 通过：55 个生产源码边界（含 `apps/web/server.mjs`），根/web TypeScript 通过。单元 15 文件 412 测试、API 集成 12 文件 104 测试、Node socket 代理 12 测试、完整 E2E 40 项全部通过，合计 **568 = 412 + 104 + 12 + 40**；隔离构建通过，不重复累加局部次数。

包含全文优先/超预算检索、稳定前缀与 Anthropic 单断点、设置控制的旧知识联想、显式历史资料引用、可选排期/缓存、计量、冻结重试，以及 H2 模型窗口/完整提示预算、只读预检与正式答案保护；额外修复回归暴露的登录返回期间可编辑竞态，两个受控延迟真实 RSC 的测试通过。全部使用离线 Provider、合成凭据与临时库，不调用真实模型。完整命令与保留边界见[最终验证记录](./审查修复记录.md#最终验证)。
