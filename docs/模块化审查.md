# 模块化审查

## 结论与范围

分层总体适合单用户应用，不需要微服务、通用插件总线或多 worker 租约。`LearningService` 与业务聚合仍集中，不能宣称完全解耦或已支持大规模数据。

本轮改造已通过**离线全量回归与隔离构建**，实际命令及结果见[审查修复记录](./审查修复记录.md#最终验证)；本文审查职责与边界，不把离线结果等同于真实 OAuth/Provider 验证或公网渗透测试。稳定行为见[产品与架构规格](./产品与架构规格.md)，本轮状态见[实现状态与偏差表](./实现状态与偏差表.md)，为什么如此选择见 [ADR 0001](./decisions/0001-单用户架构.md)。原[项目审查报告](./项目审查报告.md)保留原文。

## 职责与依赖

| 模块 | 职责 | 边界 |
|---|---|---|
| `contracts` | 类型、运行时校验、浏览器安全 DTO、统一 `LIMITS` | 不依赖 Fastify、数据库或 Pi；OAuth 凭据不进入公共 DTO |
| `learning-domain` | 状态机、内容与证据版本、范围/预算、幂等和 FSRS | 依赖 `StateRepository` / `LearningEngine` 接口，不导入具体存储或 Provider；确定性资料选段属于业务输入构造 |
| `database` | PGlite/Drizzle、物理迁移、快照缓存、串行事务/CAS、备份校验 | 物理 v3：原文拆 `app_documents`、任务输入拆 `app_run_tasks`、其他业务聚合；物理版本不混入逻辑备份版本；不管理 OAuth |
| `learning-agent` | 无工具的单次 Pi Agent 请求、提示词、输出校验、用量观测 | 不提交业务状态，不给模型文件/SQL/Shell 工具；由宿主注入凭据 |
| `ai-access` | 显式 Provider 注册、OAuth 生命周期、私有加密 vault | 不依赖学习数据库/会话/HTTP；复用 Pi 原生 OAuth 和刷新协议 |
| `ai-usage` | 时区年度聚合、已知/未知 token、热力分级 | 纯函数，不读凭据、数据库、HTTP 或当前时钟 |
| `local-storage` | 数据库和 vault 共用的目录独占锁 | 有两个实际消费者，不让数据库与凭据包互相依赖；不是集群锁 |
| `apps/api` | 身份、HTTP、可信代理边界、运行生命周期 | 组装模型选择与单执行器；`routes/ai.ts` 为配置/授权/统计适配；库不能反向依赖 API |
| `apps/web` | 页面、版本/增量状态及按需全文、局部配置交互 | 只依赖公共契约，不接触 Pi 或凭据；无 SSE 消费，不把原始模型输出当公开 UI 流 |

`scripts/check-boundaries.mjs` 纳入 `npm run check`，本轮 50 个生产源码（含 `apps/web/server.mjs`）及根/web TypeScript 检查通过。边界检查覆盖静态 import/export、字面量动态 import、跨包相对引用与工作区依赖声明；不等于任意运行时代码分析或沙箱。工作区和依赖已建立，静态设计已导入，不再使用旧手册“目录尚未创建”的表述。

## 关键边界及本轮变化

### 1. 业务成功与计量分开

既有 `onUsage` / `recordUsage` 按 run/attempt 记录已观测用量，不因取消或业务校验失败抹除计量。本轮 H5 进一步允许有效内容在 usage 缺失时成功，保留 `null` / 未知及适用预留，不制造零费用；已通过离线回归。

成功仍须通过完整输出、真实 source、当前范围与活动版本校验。H1 要求至少一个实际来源，原始复述可以作为 source，但来源存在不等于外部事实核验。

### 2. 存档、外发与公开 DTO 分开

统一 `LIMITS` 由 contracts 提供；上传字节预算不等于任务 JSON 字符预算。API 层先离线规划输入：授权来源放得下就全文发送，超预算才按剩余空间做 BM25 检索；追问与会话测验共用稳定来源，问答过长先省略较早作答；再经 H2 去重/过滤和预算。Agent 统一构造完整系统/分任务 Schema/user 提示，按所选模型窗口、UTF-8 字节保守估算及输出/512安全预留进行离线准备和执行前拒绝。API 将同步准备策略注入领域事务，预览与入队共用，不把 Provider 依赖引入领域包。原文保留；本地词面 RAG 不等于语义检索或摘要，grade 不截正式答案/rubric。跨会话资料必须明确引用；旧知识联想由设置控制、自动选择并冻结版本，不作来源、不新增考核点，复习只回查本知识点原始来源。只读预检包含资料/私有评分标准但只回数字和节选条目，浏览器不读私有题目；预检不调用模型、不写库、不创建任务。

本轮移除未被消费的旧 SSE；`GET /api/state?since=revision` 返回 `unchanged/snapshot/delta`，delta 为 `upsert/remove`。仅保留 16 个指纹基线，未知 revision 返回快照，不保留多份全状态。初载仍包含全部公共实体（资料仅 metadata），不是分页；登录后 `GET /api/documents/:id` 按需读取全文，首次状态不带全文；`/api/me` 仅读内存中的小型设置投影，不查 SQL 或克隆全聚合。以上已通过 API/E2E 回归，不宣称所有客户端查询都已取消。

### 3. 单执行器、存储和生命周期

持久化 run 与入队后唤醒替代空闲 worker 轮询；仍有取消、run/attempt fencing 与重启恢复，不做多 worker 租约。缓存快照必须防止调用者改写共享状态，并正确处理失败/恢复；相应离线回归已通过。

物理 schema v3 把文档原文拆到 `app_documents`、AI 任务输入拆到 `app_run_tasks`，其他业务继续聚合；AppData JSON 备份 schemaVersion 仍 1。旧物理 v1/v2 事务升级、快照缓存和串行事务/CAS 已通过临时库回归。全聚合内存及写校验开销仍在，不宣称只改一项就解决全部规模问题。

仅已知 CAS 草稿/理解/回忆暂存回执在后续新命令内按 24h / 最多 2,000 条清理，含 runId、未知操作及其他非暂存收据长期保留；不是所有非计费 command 都自动删除，业务幂等与长期计费防重放不能统一套 TTL。恢复旧备份不能保证永久去重。学习、证据及原文不自动到期。

升级前停服并运行 `npm run data:export -- ./backup-before-v3.json --before-migration`；兼容已有物理 v1/v2/v3，加锁后在 SQL 只读事务中完整导出，不初始化或升级 schema，无需旧程序副本。临时 v1 CLI 已验证 schema 仍 1、0600、wx；PGlite 自身 WAL 恢复可能写盘，不承诺磁盘零写。新版物理库不支持旧程序直接打开。本轮不触碰用户真实数据库。PGlite 固定磁盘开销不能代替逻辑导出大小/延迟测量；工程目标与非强制边界见稳定规格。

### 4. 内容版本不是并发版本

M1 将知识内容快照与保存/CAS 版本分开，题目及证据绑定出题时内容版本；历史缺失标未知。M2 保留请求的结束原因但不覆盖 assessed；M4 非空回忆须实际用于出题；M3 维持 live 默认不开卡/不排期；可显式保存模式内应用偏好，开启不自动补卡，历史知识提供单点加卡。关闭排期仍可完成已交卷复习并保留证据。以上已通过离线回归，不代表真实模型质量或长期排期效果已验证。

### 5. OAuth 和 AI 配置维持独立边界

`ai-access` 使用独立 vault，不把授权状态混入学习聚合；临时 OAuth Store 只有通过身份、期限、取消状态检查才提交，刷新与删除序列化。非敏感模型选择保存在当前模式数据库，通过宿主 `AiModelRuntime` 组装；授权不自动选择模型，不启用 live，也不触发连接测试。

`useOAuth`、`ModelConfiguration`、`useConnectionTest` 和热力图各管理局部状态，避免一处轮询触发全部学习状态刷新。连接测试复用持久化任务、幂等与计量，不旁路执行 SDK 请求；参数固定，不带学习资料，不经通用学习重试自动重放。

每 Provider 仍只有一个当前连接，任务执行时读取凭据；没有排队任务账号版本绑定或多账号编排。SESSION_SECRET、vault 迁移、OpenAI/Codex OAuth 无上游输出硬限制、撤销与费用风险只在 [README](../README.md)集中维护。

### 6. 安全隔离不能被“单用户简化”抵消

身份、资源归属、CSRF/Origin 防不同风险，继续保留。开发 Web 维持 `0.0.0.0:3010` 供 WSL 使用，API 仅回环。H4 采用 Next 自定义 Node 入口读取 socket `remoteAddress`、剥离客户端转发头，HMAC 绑定 IP/时间/方法/path；API 仅在 loopback 来源且签名有效时采纳，仍 `trustProxy:false`。已通过离线代理/API 回归与真实 Next E2E；不信任任意 XFF，不用 Origin 配置冒充客户端身份。Web dev/start 必须经 npm scripts → `apps/web/server.mjs`，不支持直接 `next dev/start`；`API_INTERNAL_URL` 仅 literal loopback origin（127.* / ::1），非 localhost hostname/远程 API。Upgrade 仅 dev `/_next/hmr`（可 query）放行，生产及未知路由拒绝，退出销毁跟踪的升级 socket，12 个 Node socket 测试覆盖。NAT 在入口前合并源 IP 的限制仍在，Windows→WSL 真实网络访问本轮未人工验收。生产 HTTPS 需独立受控部署，不扩大代理信任，未完成公网审计。

L6“错误未说明变量名”是报告误差，既有 live 环境诊断已指出变量名。保留厂商/代理/TLS 环境污染隔离，不以开发便利放宽。配置以 `.env.example` 与 `apps/api/src/config.ts` 为准，不引入旧草案未实现变量。

## 保留的集中职责与演进条件

- `LearningService` 仍集中管理学习、测验、复习事务；仅文件长不构成拆抽象理由，按真实变化热点拆分。
- 其他业务仍聚合，尚未全实体拆表；不支持横向扩展。单用户 ≤1,000 知识点 / ≤500 资料 / ≤1 年日常记录是非强制工程观察目标，不是容量或延迟保证。
- HTTP 适配与领域投影的窄接口仍可改进；本轮已移除写后历史取消扫描，`/api/me` 使用小型缓存设置投影，增量传输通过回归，但不代表所有接口已完成轻量化。
- 公开多人服务、工具式 Agent、向量/语义检索和多 worker 需要独立理由及新 ADR，而非自动兑现历史手册所有展望。

## 验证结果

`npm run check`（54 个生产源码边界及根/web TypeScript）、隔离生产构建通过；单元 15 文件 404 测试、API 11 文件 99 测试、Node socket 代理 12 测试、完整 E2E 41 项全过，合计 **556**，不叠加局部次数。覆盖既有迁移/缓存/CAS/状态同步/来源/计量/IP 信任，以及 H2 补充修复的完整输入预算、服务端预检、迟到响应和私有答案隔离。本地 BM25、跨会话显式引用、旧知识版本关联、复习原文、偏好 CAS/持久化、缓存计量和冻结重试也有覆盖。登录返回导航完成前的编辑窗口仍有受控 RSC 回归。命令见[最终验证记录](./审查修复记录.md#最终验证)。

离线测试不证明真实模型质量或 OAuth 账号权限。人工真实评估须授权，见 [evaluations/README.md](./evaluations/README.md)。
