# ADR 0008：云端账号与浏览器本地学习库

状态：已实现，默认启用；部署不在本次变更范围内。

用户选择让学习资料留在各自设备，云端承担账号管理和按需 AI 网关。该决定替代 ADR 0001 的默认单用户部署方式，保留 `APP_STORAGE_MODE=server` 作为旧数据维护与兼容入口。

## 数据归属

云端 `createGatewayApp()` 装配账号、OAuth、模型目录、云 Skill 目录、显式任务执行端点及受管理员权限保护的后台，不创建学习 Repository，不注册服务器学习 CRUD。`main.ts` 在默认 `local-first` 分支打开独立账号库；只有显式 `server` 分支打开旧 PGlite 学习目录。

`openAccounts()` 持久化用户名、稳定 UUID、随机盐、scrypt 密码哈希、角色、状态、额度及网关计量。活动仅记录登录/退出、固定模块名与时间，不含路径参数、草稿或学习文本；保留 90 天。管理操作只记录操作者、目标账号、操作种类和时间，保留一年。每账号拥有独立 OAuth 目录，凭据密钥按账号 ID 派生，沿用 vault 的 AES-256-GCM、原子替换与目录锁。平台 API key 通过独立用途密钥加密保存，始终由服务端读取，不回显。账号 ID、原 `SESSION_SECRET` 和授权目录需要独立保管，学习 JSON 不包含这些凭据。

浏览器 `openBrowserRepository()` 使用 IndexedDB，以 `sanxing-learning-v1:<account-id>:<mode>` 分库，内容沿用 AppData schemaVersion 1。数据库内容不做应用层加密；账号分库提供正常应用流程中的隔离，不能抵抗控制浏览器、扩展或设备文件系统的访问者。相同账号在不同浏览器、设备、来源上是独立学习库。

## 写入与任务

浏览器复用 `LearningService`、共享 mutation 映射、复习规则、Skill 解析和纯提示词构造/预检。领域代码的同步 SHA-256、UUID 和 Base64 改为跨运行时实现，Node 适配器继续读取原提示词文件，浏览器通过登录后的 bootstrap 获取相同固定模板。业务规则没有复制到云端网关。

IndexedDB 写入采用严格事务提交与 revision CAS；Web Locks 串行化同账号同模式的写入。一个账号和模式由一个标签页持有任务执行器锁，其他标签页可正常读写；执行器定期拾取已提交的待执行任务。页面关闭、退出、账号变化或会话到期时停止本地执行器和网络等待，历史中断请求需明确重试。存储失效拒绝保存，不回退为内存成功。

草稿、输入及连续复习队列按账号划分临时缓存。跨标签页登录或退出通过 BroadcastChannel 与存储事件锁定旧页面，避免 Cookie 已切换而界面继续打开前一个账号的数据。

本地请求适配器只把明确列出的登录、目录、授权、网关、活动和后台请求交给网络；学习查询、预检和写入都在浏览器处理，未知本地端点报错。TXT、Markdown、Skill 文件与 PDF 解析不上传正文。PDF 原始字节由本地 Blob 下载。

## 网关边界

主动学习模型任务将必要的文字输入送到 `/api/gateway/execute`。主动图片 OCR 经 `/api/ocr/recognize` 临时转发到 BBC_OCR 同步端点，要求登录、Origin 与 CSRF，校验图片格式、大小及结果来源哈希；不创建 OCR 作业、保存图像或记录识别正文。用户对照原图确认后，原图、校对文本与 OCR 元数据只进入本地学习库，随学习备份保留；学习模型只接收被选中的文字。旧服务器存储模式仍保存到原有服务器学习库。

网关验证账号、Origin、CSRF、模型目录与授权，服务端重新校验模型输入及提示词版本，临时处理请求并以 NDJSON 返回进度、用量、结果或受限错误码。原始请求、模型内容和学习结果不写云端学习库、调用收据或应用日志。

网关按账号实施单并发、每日次数和可选估算预算；持久收据仅保存请求 ID、服务端 HMAC、日期、模型、状态及数字用量。重复请求 ID 一律拒绝再次调用，服务重启将运行状态记为失败，不重放潜在已计费请求。浏览器账本与云端调用账本分离，恢复本地旧备份不会删除云端防重放记录。连接池由网关持有，可跨请求复用连接，凭据仍按账号和每次调用读取。

## 管理后台与平台 AI

`ADMIN_USERNAMES` 仅在没有启用的管理员时绑定已注册账号，保留密码；注册端点不自动赋予管理权限。角色、状态和密码变更增加会话版本并撤销目标账号会话；网关在入队事务中再次校验状态与会话版本。禁止当前管理员停用或降级自身，保留至少一名启用的管理员。管理接口在云端独立校验角色，前端隐藏入口不充当权限边界。

用户显式选择 `platform / managed / platform`，本地只持久化这个非秘密选择。网关将其解析为当前平台 Provider、模型与服务端密钥，并在同一调用账本事务中检查账号权限、每用户每日额度、全站每日额度与平台并发上限。个人模型运行时不注入平台密钥，不能通过改选 `api_key` 借用平台凭据。保存平台配置使用版本检查，不自动发出测试或真实模型请求。

后台只看到云端使用元数据，不能查询用户本地学习库。服务器指标来自当前 API 实例的 OS、process 和事件循环采样；10 秒采样、内存保留最多 180 个点，重启后重新积累，不虚构历史。多实例聚合、磁盘、带宽、持久指标和告警尚未接入。

## 迁移与备份

旧学习目录、共享 OAuth vault 和 `.env` 不自动改写。停服后先用现有 CLI 导出旧学习 JSON，必要时使用升级前导出入口。新账号在对应 mock/live 模式的「本地数据与备份」确认导入；未完成任务改为失败，评分改为待核对，禁止自动重放。模型选择及 Skill 保留，OAuth 由新账号重新授权。

本地备份是包含原件、答案和任务快照的未加密 JSON，支持导出、校验后原子替换及确认清空。清空不删除云端账号、授权或用户已导出的文件。浏览器持久存储权限只能降低自动回收风险，用户清理网站数据仍会删除本地库。尚未实现自动云同步、加密云备份、邮箱验证、自助密码重置或多副本账号数据库。

## 验证入口

- `apps/api/test/gateway.test.ts`：身份、授权账号隔离、CSRF、拒绝服务器学习端点、防重放、重启及计量边界。
- `apps/api/test/admin.test.ts`：管理员绑定、权限隔离、会话撤销、活动元数据、平台密钥加密与重启恢复、模型解析、全站额度与并发限制。
- `tests/e2e/local-first.spec.ts`：真实 IndexedDB、私密笔记不上传、完整学习流程、账号/设备隔离、备份恢复、多标签页冲突、退出锁定、PDF 与存储失败。
- `playwright.local-first.config.ts` 使用独立临时账号库和 mock 模型。默认 Playwright 配置继续验证旧服务器适配器，两套均纳入 `npm run verify -- --suite browser`。
