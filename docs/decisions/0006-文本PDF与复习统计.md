# ADR 0006：文本型 PDF、可追溯统计与连续复习

状态：已实现。日期：2026-10-21。对应第三批交付：复习统计、连续复习、PDF 导入、检索改善。

## PDF 输入与来源

API 固定使用 `pdfjs-dist@6.4.299`，按 [PDF.js 的文档/页面接口](https://mozilla.github.io/pdf.js/examples/)读取上传的二进制字节和文本层。解析在独立 Node Worker 中进行，不持有数据库事务；每个应用同时只接受一项 PDF 解析，15 秒超时终止，Worker 的 V8 老生代上限为 128 MB（并非进程总 RSS 保证）。只读取本地内置字体/CMap，不运行 PDF 动作、脚本、附件或图像渲染，不请求模型和远程解析服务。

PDF 原文件单独允许最大 20 MB（20,000,000 字节）；图片 OCR 上传最大 10 MB（10,000,000 字节）。`UPLOAD_MAX_BYTES` 只限制文本笔记：默认 131,072 字节、配置上限 1,048,576 字节。PDF 另独立限制 100 页和 200,000 个 UTF-16 字符，解析按文本块检查上限，不静默截断后当作完整资料。加密、损坏、无可用文本、页数/文本超限或超时均返回明确错误，失败不留下部分文档或幂等收据。全文件无文本时提示先导出图片做 OCR；混合文件保留无文字页并标记。多栏、表格、公式的顺序与字符可能不准确，需要用户核对；尚无扫描 PDF 直接 OCR、版面重建或 DOCX。浏览器上传区展示读取、逐页解析、保存及成功/失败反馈，失败后可重新选择同一文件重试。

`DocumentRecord.import` 是兼容旧数据的可选字段，保存解析器版本、页码与解析全文行号范围，每页带可用文本标记。全文包含页标题，页范围覆盖完整解析文本；数据库导入校验连续页码、连续行号和全文行数。原始字节仍存 `originalBase64`，原始文件 SHA-256 仍存 `hash`。使用现有物理 schema v3、逻辑备份 v1，不重解析或改写旧文档。

资料详情返回文本与页码映射；初始状态仍仅包含 metadata。共享来源阅读器支持选择 PDF 页码和全局行号。`GET /api/documents/:id/original` 必须登录，按附件下载保留的原始字节，不内嵌执行 PDF。上传仅附加到草稿，正式提交时才进入原有授权来源及输入预算流程；其他资料、原始二进制和未明确关联的个人理解不会自动加入模型输入。

## 检索

`POST /api/library/search` 保持只读、鉴权及 CSRF/Origin 检查。新增 `offset`、`limit`（默认 10，最大 50）、`expectedRevision`、`includeUnderstanding`、`expandTerms`；响应包含总数、下一页 offset、当前 revision 与实际扩展词。稳定排序，每个实体只取最高相关片段。翻页前版本不符返回 `SEARCH_CHANGED`，要求重新搜索，不把变化后的页拼成旧结果。

“我的理解”是可选的独立搜索字段。命中时标明当前个人笔记，不使用知识内容版本冒充它的历史快照；归档知识仍排除。PDF 命中附带该片段覆盖的页码。可选术语扩展由 `packages/learning-domain/src/search-terms.ts` 中的版本化表维护，覆盖 FIFO/LIFO、DP、BFS/DFS、二分查找、记忆化、缓存、哈希表、标准差等中英文词组；ASCII 缩写按词边界匹配。默认仍为原 BM25；扩展仅影响用户的本地检索，不改变自动联想、授权来源和任务冻结行为。10 组固定查询对照覆盖这些映射，不能据此声称开放领域语义检索准确率。

## 复习统计的口径

`GET /api/learning/statistics?days=7|30|90|0` 返回纯计算投影（0 为全部）。按用户时区的自然日筛选，日期范围包含今天，未来时间记录排除；区分 mock / live。统计只包含已交卷测验的当前作答证据，按测验与题目去重，评价历史不再累加。类别互斥，优先级为：跳过 → 待核对/未解决争议 → 评价中 → 人工自评 → 辅助已评价 → 独立已评价。

即时考核与延迟回忆的独立表现分别展示作答数、满分次数及累计得分/满分，不称为掌握率。常见失分项仅采用已保存的独立分项评分，按知识点和评分描述分组，不把不同题目的局部 rubric ID 当成同一个能力维度。每个汇总保留 evidence、quiz、question 和评价版本，可点击原题核对；缺失分项依据的旧记录不补造。

复习完成次数按完成时间统计；排期事件次数按原始作答决定的 `reviewedAt` 统计，可能位于不同日期，两者不要求相等。未来 7 天负担按当前 due 的本地自然日分桶；今天包含尚未到时的卡片，今天前逾期、更晚到期、暂停及知识归档单列。实际已到期队列仍比较精确时间。未加入预测保持率、个性化训练或学习效果承诺。

## 连续复习与暂停

连续复习由用户主动开始，当前标签页 `sessionStorage` 保存本轮到期卡 ID、已开始卡 ID 与当前复习会话。刷新及暂离可恢复；退出登录清除，不承诺跨设备或关闭标签页恢复。下一张只在用户点击时开始，不自动提交回忆、出题或评分；跳过已访问、暂停、归档或本轮开始后已经完成的卡片。调度关闭导致卡片仍到期时，本轮也不会重复访问。

单卡会话创建沿用服务端复用活动会话、幂等及 CAS；完成仍最多产生一次排期事件。`PUT /api/reviews/:id/pause` 带卡片版本和 `paused`，只改变参与状态及并发版本，保留原排期和历史事件。活动复习必须先完成或放弃，不能在中途暂停破坏其版本。暂停卡从队列与到期徽标排除，恢复沿用原到期时间。

原 `mapping-v1` 提取到 `review-policy.ts` 并保留相同事件版本字符串：任一有效独立作答未满分则 Again，全部满分采用用户评级；无有效独立作答不排期。没有调整算法参数或回写历史事件。
