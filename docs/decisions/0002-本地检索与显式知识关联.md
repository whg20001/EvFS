# ADR 0002：本地检索、显式知识关联与可选提示缓存

> 部分已被 [ADR 0003](./0003-全文优先-稳定前缀与自动旧知识联想.md) 取代：固定检索配额改为全文优先、超预算才检索；追问不再固定只带两轮；手动关联旧知识改为设置控制的自动联想；Anthropic 改为稳定块单断点；提示版本为 `learning-v5`。以下保留原决定作为历史记录。

## 背景

资料已完整存档，但过去只在所属复述内使用。预算裁剪不是检索；只按规范化标题匹配旧知识，也不够支持概念之间的比较。单任务独立 Agent 避免无限对话历史，却不免除重复发送资料的成本。

## 决定

- 使用本地中文/英文分词、按行分块和 BM25 词面评分，不调用 embedding、摘要或额外模型请求。资料库搜索支持历史资料和已确认知识；空查询不枚举整个资料库。首次实现按需计算，不维护第二份权威向量库或持久索引。
- 全库检索仅供用户选择。历史文档必须明确附加到草稿，旧知识必须在范围确认时明确关联，才进入后续模型上下文；搜索本身不扩大外发范围或考核范围。
- 文档继续使用不可变 ID/原文，`recitationId` 表示上传出处。其他复述引用同一文档 ID，移除只解绑，不复制或删除原文，不影响历史学习快照。引用与新上传共享资料数量限制。
- “关联旧知识”与“复用知识点”是不同动作：前者保存最多三个旧知识内容版本的冻结快照，只作比较；后者更新已有知识点当前内容并保留内容历史。题目仍只能绑定本次接受的知识点及该点获准的来源。
- 复习出题回看该知识点实际引用的原始文档、已提交复述；缺失来源不以无关全库材料替代。此前确认的描述仍作为可能有误的背景，不能当成外部事实核验。
- 新任务先从获准来源检索有行号的有限片段，再执行 H2 的任务 JSON 与完整模型窗口预算。原始复述和正式答案的既有保护保留；grade 的答案/rubric 不做检索或静默截断。追问仅携带当前范围最近两轮问答，完整历史仍保存。
- 无词面命中时使用明确标记的有限首尾背景，不宣称相关命中、全文阅读或语义覆盖。检索结果冻结到 run.task，显式重试复用冻结输入，不重新检索。执行阶段仍只检查预算，不暗改输入。
- 学习提示版本升级为 `learning-v4`，历史版本不回写；连接诊断仍是 `connection-v1`。

## 可选设置与缓存

`learningPreferences` 与学习数据一同持久化，mock/live 隔离。旧数据缺少该字段时，排期继承现有环境配置（live 默认关闭），提示缓存仍为 `none`。页面保存需要明确确认、revision CAS 和幂等键，活动任务期间不允许切换。无需修改私人 `.env` 或重启来保存这两个应用设置。

开启排期不批量补历史卡；知识详情提供单点明确加入复习。关闭后可以完成已交卷复习、保留证据，但不推进卡片或生成排期事件。

短缓存是可选的厂商提示缓存，不是本地缓存模型答案。独立 Agent、单请求和零自动重试不变。稳定内容尽量先于动态问答排列；按学习会话用目的限定 HMAC 生成不含正文/身份/凭据的亲和键。连接测试始终不请求缓存。

Pi 的 `cacheRetention` 对厂商的含义不同：

- OpenAI API key：短缓存可携带缓存亲和键；实际 TTL/缓存行为由模型和厂商决定。
- OpenAI OAuth/Codex：不能借此承诺 TTL、命中或上游输出硬上限；Codex 的 short/long 在当前实现没有对应的不同 TTL。
- Anthropic：短缓存使用 ephemeral 标记。当前单 JSON 用户消息没有独立文档断点，改变动态内容时未必复用文档前缀。
- `none` 表示应用不请求上述短缓存策略，**不保证所有厂商完全不缓存，也不能据此断言全部输入按全价计费**。

记录上游已观测的缓存读/写 tokens；它们已包含在总输入里，不重复累加。旧记录缺少缓存计数时标未知，不补造零命中。用量和目录费用估算不等于厂商账单。

## 兼容与边界

逻辑备份 `schemaVersion` 仍为 1，物理数据库保持现有 v3；本次没有新物理迁移。新增设置及关联快照接受旧字段缺失，恢复时校验显式关联版本和内容，不伪造历史。新字段写入后的数据不承诺可由旧程序打开；回滚使用升级前备份与兼容程序，不原地降级。

本地 BM25 是词面检索，不是语义近义识别、知识图谱、自动摘要、全库自动考核或事实核验。相关度不代表可信度或学习掌握程度。容量仍受单用户聚合内存与按需索引开销约束；减少输入字符不等于保证节省相同 token 或金额。

验证只使用离线 Provider、合成数据、内存/临时库和隔离测试端口。真实命中率、费用、账号权限、模型质量及长期复习效果须另外授权和评估。
