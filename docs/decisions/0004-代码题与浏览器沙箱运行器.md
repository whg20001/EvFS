# ADR 0004：代码题与浏览器沙箱运行器

状态：已采纳。日期：2026-10-10。

## 背景与决定

学习与复习测验允许混合单选、简答和代码题。设置中的「代码题」默认关闭，默认语言为 Python；语言至少选一种，支持 Python、JavaScript、TypeScript。开启后由模型判断当前知识点是否适合编程，不要求每轮都有代码题。mock 为便于回归，固定把最后一题生成为所选第一种语言的演示代码题。

代码题提供中文注释骨架（目标、输入输出、步骤、TODO）和 1–6 条可见测试。骨架最多 8,000 字符，给 12,000 字符答案留出空间；每条测试最多 2,000 字符。测试能访问答案定义的变量和函数，逐条执行，抛异常即失败。JS/TS 提供 `assert`、`assertEqual`（递归比较）、`assertClose`；TS 用 sucrase 去除类型，不做类型检查，不提供 npm 模块导入。

## 执行边界

代码只在浏览器内执行。父页面创建 `sandbox="allow-scripts"` 的 iframe，不包含 `allow-same-origin`；iframe 从本地运行时目录取得程序，创建经典 blob Worker。Chromium 在不透明源中拒绝 module blob Worker，因此使用 esbuild 的 IIFE 输出，Pyodide 通过 Worker 中的动态 import 加载。

`next.config.ts` 的 `headers()` 在 `/code-runner/runner.html` 设置：

- `sandbox allow-scripts`：直接访问或被无 sandbox 的父页面嵌入时也保持不透明源。
- `frame-ancestors 'self'`、`default-src 'none'`、`base-uri 'none'`、`form-action 'none'`。
- script/connect 仅允许当前 Host 的 `/code-runner/` 目录；脚本允许 eval/WASM 和 blob，Worker 只允许 blob。不会放开 API 或外网。
- Host 插值仅接受主机名、IPv4 和可选端口；不匹配的 Host 仍收到禁用脚本的 sandbox CSP，按拒绝执行处理。

`/code-runner/:path*` 返回 `Access-Control-Allow-Origin: *`，不启用凭据，允许不透明源读取本地公开运行时文件。普通 API 不获得这项 CORS。自定义 server.mjs 继续将这些静态请求交给 Next。

父子 postMessage 均要求有界 JSON 字符串（最多 65,536 UTF-16 字符）、协议版本、UUID 请求 ID 和结构校验。iframe 校验 `event.source === parent` 与父来源；父页面校验当前 iframe 的窗口引用与 `origin === 'null'`。发往不透明源必须使用 `targetOrigin='*'`，窗口引用和随机请求 ID 用于关联消息；输出始终是不可信证据。父页面与 iframe 共用 Zod Mini 校验；Worker 接收 iframe 已验证的结构化请求，回包仍由 iframe 校验。编辑、取消或切题立即作废旧结果；在途运行结束或超时后才发送最新排队请求，旧结果不会进入答案。

Worker 准备阶段上限 90 秒，执行阶段 10 秒；iframe 超时终止 Worker，下次运行新建。父页面另设 105 秒硬超时，销毁并重建 iframe，以覆盖运行器自身未响应。stdout/stderr 合并最多 4,000 字符，运行中回传有节流，逐条错误摘要最多 500 字符。浏览器没有可靠的每 Worker 硬内存限额，恶意内存耗尽仍可能影响标签页；本功能面向单用户学习，不是多租户在线判题服务。

## Python 本地运行时

固定 `pyodide@314.0.7`。构建脚本从 npm 包复制核心 JS、WASM、标准库 ZIP、锁文件至 `apps/web/public/code-runner/pyodide/`。独立下载命令 `npm run code-runner:packages` 读取锁文件的 `depends` 递归求闭包，从同版官方发布目录 `https://cdn.jsdelivr.net/pyodide/v314.0.7/full/` 下载 wheel，并核验每份文件的 SHA-256；拒绝重定向和哈希不匹配，以临时文件完成后重命名。当前闭包为 numpy、scipy、scikit-learn、joblib、threadpoolctl；已有文件也必须通过哈希校验才复用。

`loadPyodide` 显式设置本地绝对 `indexURL`、`lockFileURL`、`packageBaseUrl`、`cdnUrl`。同时扫描答案与测试中的 import 后预加载依赖。包加载器即使只通过错误回调报告缺包，也会转为包含安装命令的可见错误。运行期间不从 CDN 下载。页面级运行器首次运行时创建 iframe，编辑、取消和切题均保留 iframe 与 Python Worker；Python 每次运行新建 globals，解释器及已加载的包在页面生命周期内复用，模块自身状态可能跨题保留。JS/TS 每次使用全新 Worker，结束后销毁，不影响常驻 Python Worker。iframe 内超时只终止当前 Worker，父页面硬超时才重建 iframe；每个 iframe 缓存一份 Worker 脚本 Blob URL。

核心生成直接写进 web 的 dev/build/start、根 setup 和 Playwright 启动命令。仓库的 npm 配置启用 ignore-scripts，会跳过生命周期钩子，因此不使用 pre* 钩子。生成目录整体忽略提交，构建仅在内容变化时写入产物，避免重置未变资源的 mtime；构建不自动下载 wheel；新机器须在首次 Python 使用及完整 E2E 前执行一次包下载命令。生产启动需要具备生成脚本的开发依赖。缺 wheel 的 Python E2E 明确失败，不跳过。

## 数据与界面

- CodeMirror 6 动态加载，使用设计 token 和深色语法颜色，适配窄屏；明确 TS 不做类型检查。保留编辑、暂存、重置确认、跳过、提交前预算预检。
- 公共投影新增 `hasDraft` 区分不存在草稿与空字符串。无草稿使用骨架，主动清空后保持为空；编辑清空旧运行报告。
- `execution` 包含状态、通过数、总数、有界输出、耗时、运行时间，随预检和正式答案进入 grade。未运行也可提交。只有代码题可携带 execution，总数须等于题目的测试数；跳过不能携带 execution。
- 代码题与简答都由模型按固定 rubric 评价，入队时分数为 null，修复 `null === null` 导致满分的问题。浏览器通过测试既不能自动满分，未运行也不能自动判零；mock 只返回待核对。
- 代码题正式操作要求 `codeProtocol: 1`，旧客户端收到刷新提示，避免用旧文本表单误交代码题；旧单选、简答请求保持兼容。
- 偏好缺省保留既有值，语言按固定顺序去重；旧数据仍为关闭/Python。数据库验证题目、任务、偏好与答案，沿用现有 schema，无物理迁移。
- `learning-v6` 提示，quiz 的 code 偏好放动态块，不改变稳定资料前缀；grade 明确将 execution 视为不可信辅助证据。历史任务不回写。

## 验证范围

契约/持久化、引擎输出与 payload、提示关键词、领域/API 入队及兼容性均有离线测试。浏览器覆盖真实 mock 学习闭环、移动端深色编辑器、JS/TS/Python、科学包只在测试中 import、WASM 复用、缺包提示、输出截断、死循环恢复、父硬超时、双向消息拒绝及 API/外网/模块/WebSocket 阻断。测试使用内存库、合成凭据及 3027/4107；实际次数见[最终验证](../审查修复记录.md#最终验证)。
